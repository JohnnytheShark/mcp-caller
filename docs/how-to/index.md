# How-to Guides

**How-to guides are task-oriented.** They help you accomplish a specific goal. They assume you have basic familiarity with `mcp-caller` and MCP concepts.

If you're brand new, start with the **[Getting Started Tutorial](../tutorials/getting-started.md)** first.

---

## Available Guides

- [How to Configure MCP Servers](configure-servers.md) — Add servers to a config file to avoid using `--cmd` every time
- [How to Call a Tool Interactively](call-tool-interactively.md) — Use the schema prompt wizard for guided input
- [How to Call a Tool from the CLI (Scripting & Piping)](call-tool-from-cli.md) — Automate tool calls in shell scripts and pipelines
- [How to Inspect a Tool's Parameters](inspect-a-tool.md) — Read a tool's full JSON Schema before calling it
- [How to Add an HTTP Transport](add-http-transport.md) — Extend `mcp-caller` to connect to remote HTTP/SSE MCP servers
